# AutoClick HH 🚀

Автоматизированная система для откликов на вакансии на HeadHunter (HH.ru) по ключевым словам "go" и "golang".

## 🎯 Возможности

- **Автоматический поиск** вакансий по ключевым словам
- **Умные отклики** только на подходящие вакансии
- **Отслеживание** уже откликнувшихся вакансий
- **Лимитирование** количества откликов в день
- **Безопасность** - проверка дублирования откликов
